# پیام‌رسان سوکوت (Sukot Messenger)

پیام‌رسان زنده و واقعی اندروید برای گفتگو با مخاطبین‌تان از راه دور — با رابط کاربری کاملاً فارسی و طراحی متریال.

**سازنده: Sukot**

## امکانات

- گفتگوی زنده (Realtime) با هر کسی که این برنامه را نصب دارد
- افزودن مخاطب فقط با «شناسه کاربری» — بدون نیاز به شماره تلفن
- رمزنگاری AES-256-GCM روی محتوای پیام‌ها
- ذخیره تاریخچه گفتگوها در دیتابیس محلی (SQLite)
- نوتیفیکیشن پیام جدید + سرویس پیش‌زمینه برای اتصال دائمی
- تیک وضعیت پیام (در حال ارسال / ارسال شد / تحویل شد)
- طراحی متریال ۳ + پشتیبانی کامل راست‌به‌چپ (RTL)
- سازگار با گوشی‌های شیائومی (MIUI) و اندروید ۸ به بالا

## دانلود و نصب

1. به بخش [Releases](../../releases/latest) بروید و فایل `SukotMessenger-1.0.0.apk` را دانلود کنید.
2. روی گوشی، اجازه «نصب از منابع ناشناس» را برای مرورگر یا فایل‌منیجر فعال کنید.
3. فایل را باز کرده و نصب را تأیید کنید.

### نکته برای گوشی‌های شیائومی (MIUI)

- تنظیمات ← مجوزها ← **اجرای خودکار (Autostart)** را برای «پیام‌رسان سوکوت» فعال کنید.
- تنظیمات باتری ← برای این برنامه گزینه «بدون محدودیت» را انتخاب کنید تا همیشه آنلاین بمانید و پیام‌ها را زنده دریافت کنید.

## نحوه استفاده

1. در اولین اجرا یک **شناسه کاربری** انگلیسی (مثلاً `ali_1380`) و یک نام نمایشی انتخاب کنید.
2. شناسه‌تان را برای دوستان‌تان بفرستید (لمس نوار سبز بالای صفحه گفتگوها = کپی شناسه) و شناسه آن‌ها را بگیرید.
3. با دکمه **+** شناسه مخاطب را وارد کنید و گفتگو را شروع کنید.
4. پیام‌ها بلافاصله تحویل می‌شوند؛ وقتی مخاطب پیام را دریافت کند، تیک پیام شما به **تیک دوگانه** تبدیل می‌شود.

> هر دو طرف باید اپلیکیشن را نصب و باز (یا در پس‌زمینه فعال) داشته باشند تا پیام‌ها لحظه‌ای تحویل شوند.

## معماری فنی

| بخش | فناوری |
|---|---|
| زبان | Kotlin |
| ارتباط زنده | MQTT (بروکر عمومی broker.emqx.io) |
| رمزنگاری پیام | AES-256-GCM |
| دیتابیس | SQLite |
| پس‌زمینه | Foreground Service |
| حداقل اندروید | 8.0 (API 26) |

### نکته امنیتی

این نسخه برای تبادل پیام از یک بروکر عمومی استفاده می‌کند و محتوای پیام‌ها با کلیدی که از شناسه دو طرف مشتق می‌شود رمزنگاری می‌گردد (سطح امنیتی دمو/شخصی). برای استفاده کاملاً محرمانه و حرفه‌ای، پیشنهاد می‌شود سرور MQTT اختصاصی راه‌اندازی شود تا همه ترافیک روی سرور خودتان بماند.

## بیلد از سورس

```bash
./gradlew assembleRelease
# خروجی: app/build/outputs/apk/release/app-release.apk
```

نیازمندی‌ها: JDK 17+ و Android SDK (API 34).

این پروژه دارای GitHub Actions است: با هر تگ `v*`، فایل APK به‌صورت خودکار بیلد و به بخش Releases اضافه می‌شود.
