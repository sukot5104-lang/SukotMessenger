# پیام‌رسان سوکوت (Sukot Messenger) — نسخه ۲

پیام‌رسان زنده و واقعی اندروید با **ورود از طریق شماره موبایل و کد تایید پیامکی** — دقیقاً مثل پیام‌رسان‌های واقعی.

**سازنده: Sukot**

## تازه‌های نسخه ۲.۰.۰

- ورود با **شماره موبایل + کد تایید پیامکی (OTP)** — با قالب پیامکی مثل نمونه واقعی: «با سلام، کد تایید شما: 123456 سوکوت»
- **خواندن خودکار کد از پیامک** (با اجازه شما کد خودبه‌خود پر می‌شود)
- **آنلاین / آخرین بازدید** مخاطب در بالای گفتگو
- **«در حال نوشتن…»** (Typing) زنده
- **نشان تعداد پیام خوانده‌نشده** روی هر گفتگو
- **جداکننده تاریخ شمسی** (امروز / دیروز / تاریخ) بین پیام‌ها
- **آواتار رنگی یکتا** برای هر مخاطب + نمایش نام ذخیره‌شده
- **کپی پیام** با نگه‌داشتن انگشت روی هر پیام
- صفحه **پروفایل**: ویرایش نام، کپی شماره، **اشتراک‌گذاری کارت**، خروج از حساب
- تشخیص **عضویت شماره** هنگام افزودن مخاطب (از سرور)
- یادآوری خودکار نام فرستنده برای شماره‌های ناشناس

## امکانات پایه

- گفتگوی زنده (Realtime) بین کاربران
- رمزنگاری AES-256-GCM روی محتوای پیام‌ها
- تاریخچه گفتگوها در دیتابیس محلی (SQLite)
- تیک وضعیت پیام (در حال ارسال / ارسال شد / تحویل شد)
- نوتیفیکیشن پیام جدید + سرویس پیش‌زمینه برای اتصال دائمی
- طراحی متریال ۳ + پشتیبانی کامل راست‌به‌چپ (RTL) و شیائومی (MIUI)
- اندروید ۸ به بالا

## دانلود و نصب

1. به بخش [Releases](../../releases/latest) بروید و فایل `SukotMessenger-2.0.0.apk` را دانلود کنید.
2. اجازه «نصب از منابع ناشناس» را بدهید و نصب کنید.
3. اگر نسخه ۱ را دارید، همین فایل **روی آن نصب می‌شود** (بدون حذف) — اما به دلیل تغییر سیستم ورود، باید دوباره وارد شوید و گفتگوهای قبلی (مبتنی بر شناسه) ریست می‌شوند.

### نکته شیائومی (MIUI)

- تنظیمات ← مجوزها ← **اجرای خودکار (Autostart)** را فعال کنید.
- باتری ← بدون محدودیت، تا همیشه آنلاین بمانید.

## راه‌اندازی ورود پیامکی (مهم)

ورود واقعی با کد پیامکی به یک **سرور کوچک + درگاه پیامک** نیاز دارد:

1. **سرور:** پوشه `server/` این ریپو یک سرور Node.js بدون وابستگی است. کافی است روی یک VPS یا پلتفرمی مثل Render/Railway اجرا کنید:
   ```bash
   node server.js
   ```
   راهنمای کامل: [server/README.md](server/README.md)
2. **درگاه پیامک:** یکی از این‌ها را بگیرید و کلیدش را به سرور بدهید:
   - **کاوه‌نگار** (kavenegar.com) — محبوب‌ترین درگاه ایران
   - **SMS.ir** — با قالب تایید (Verify Template)
   - **حالت dev** — بدون درگاه؛ کد در خود پاسخ API برمی‌گردد (فقط تست)
3. **برنامه:** در صفحه ورود روی «آدرس سرور» بزنید و آدرس سرور خود را وارد کنید. حالا با شماره موبایل وارد شوید!

> اگر سروری ندارید، دکمه «ورود آزمایشی» در پایین صفحه ورود بدون کد پیامکی وارد می‌شود (فقط برای تست).

### امنیت سرور

سرور دارای محدودیت‌های سخت‌گیرانه ضد سوءاستفاده است: حداکثر ۱ کد در دقیقه و ۱۰ کد در روز برای هر شماره، انقضای ۵ دقیقه‌ای کد و حداکثر ۵ تلاش اشتباه — تا هیچ‌وقت نتوان از آن برای ارسال انبوه پیامک استفاده کرد.

## معماری فنی

| بخش | فناوری |
|---|---|
| زبان | Kotlin |
| ارتباط زنده | MQTT (بروکر عمومی broker.emqx.io) |
| ورود | شماره موبایل + OTP پیامکی (سرور اختصاصی) |
| رمزنگاری پیام | AES-256-GCM |
| دیتابیس | SQLite |
| پس‌زمینه | Foreground Service + Last-Will برای آخرین بازدید |
| حداقل اندروید | 8.0 (API 26) |
